# KevinLauncher

一个面向 Windows 的**高自由度多应用启动器**，内置米哈游三款游戏（原神 / 崩坏：星穹铁道 / 绝区零）
与明日方舟的扩展模块。

**界面精致**：整体毛玻璃质感，每个应用都可单独设置主题色、亮/暗玻璃、背景图与模糊/暗化程度，
文字颜色跟随主题色自动适配黑/白；安装程序同样是**完全自绘的整页界面**（主题色流光背景 + 线性进度条），
应用内升级则以左侧导航的环形进度条呈现，动效细腻、不打断操作。

**自定义程度高**：任意程序都能作为启动项；应用图标可框选裁剪或直接从 `exe / bat / lnk` 提取；
界面字体、启动器图标、关闭行为、启动后行为、**数据目录**都可自行配置，全部设置支持一键导出 / 导入还原。

> 本项目为**非官方第三方工具**，与 miHoYo / HoYoverse / Hypergryph 无任何关联。
> 功能与接口流程参考了 [Starward](https://github.com/Scighost/Starward)，详见 [THIRD-PARTY-NOTICES](./THIRD-PARTY-NOTICES.md)。

仓库地址：https://github.com/KevinYuHere/KevinLauncher

## 功能

### 通用（任意应用）

- 任意程序均可作为启动项：`exe` / `bat` / `cmd` / `ps1` / `lnk`（快捷方式按其当前指向直接通过资源管理器打开）。
- 以**管理员身份**运行（自提权，启动游戏客户端不需要每次都弹 UAC）；启动后可跟踪并结束进程。
- 图标：可选择图片，或从 `exe / bat / lnk` 中提取图标，并支持**框选 + 缩放**裁剪。
- 使用时长统计：总时长、每日时长、热力图；按会话记录。
- 截图图库：浏览截图目录，缩略图按需生成，大图在独立查看器窗口打开。
- 外观：每个应用可单独设置主题色、亮/暗玻璃、背景图与背景模糊/暗化；主题色自动适配黑/白文字。
- 启动器设置：启动器图标、界面字体、关闭按钮行为、启动应用后的行为、**数据目录**、全部设置的导出 / 导入备份。
- 后台行为：**单实例**（重复打开只把已有窗口切到前台）、**托盘常驻**、**开机自启**（计划任务，登录时静默提权）。

### 检查更新与安装

- **检查更新**：基于 GitHub Releases。检查结果**缓存 24 小时**（手动与自动检查都复用缓存且不刷新计时），
  并优先走**不计入 API 限额**的 `releases/latest/download/` 资源地址，`github.com` 不可达时才回退 GitHub API。
- **应用内升级**：根据清单对比，运行库不变时只需下载约 **0.1 MB 的应用载荷**；左侧导航（设置按钮上方）显示
  **独立的更新图标**（黑/白跟随主题，未开始下载时悬停不弹层），点击开始；下载中为环形进度，
  **点击暂停 / 继续**，悬停显示百分比、已下载 / 总大小与预计剩余时间；下载完成后显示**安装进度**（不可暂停），
  解包到新版本目录、改写版本指针后自动重启，**全程不阻塞界面**。
- **运行库升级**：当新版本包含 Electron 升级时，改为下载**完整安装程序**、校验后**自动打开安装包**完成覆盖安装。
- **安装程序**（`KevinLauncher-Installer-<版本>.exe`，约 71 MB，自解压包，始终以安装模式运行）：
  **完全自绘**的整页界面（主题色流光背景、主题色线性进度条）；可选择**安装目录**与**用户数据目录**
  （两者不能互相包含，路径会自动补全层级）；检测到已安装时自动填入该目录做**覆盖安装并保留全部用户数据**，
  覆盖前按 PID 精确关闭该目录的旧实例；自动写入**开始菜单 + 桌面快捷方式**、**卸载入口**
  （可在 Windows「设置 → 应用」中卸载）、并以计划任务**默认开启开机自启**。
- **卸载**：复用同一个 exe（`--uninstall`），自绘卸载界面，可勾选**是否保留用户数据**（默认保留）。

## 游戏模块

- **抽卡记录**：原神 / 崩坏：星穹铁道 / 绝区零（从游戏 web 缓存读取）与明日方舟（账号登录授权）。
  支持卡池分类、5★/4★ 统计、保底计数、记录分页；抓取过程**不阻塞界面**，结果在顶部通知栏提示。
- **游戏更新与预下载**：米哈游 Sophon 全量 / 文件级增量 / 差分补丁（HDiffPatch），明日方舟分包更新。
  支持**多线程分块下载**、**断点续传**（已完成文件按大小 + MD5 跳过）、**校验失败自动重试**，
  以及**预下载 → 正式更新复用**（只下载缺失部分）。
- 下载界面：进度环 + 百分比，悬停显示速度 / 已下载与总大小 / 预计剩余时间；点击可暂停 / 继续。
