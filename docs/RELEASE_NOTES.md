## KevinLauncher 1.0.2

### 修复
- **安装器显示真实版本**：覆盖安装时不再显示旧版本号（此前应用内升级后，安装器读到的仍是上次「安装程序」写入的版本）。
  现在以安装目录里的版本指针为准，并会同步卸载入口与安装标记，Windows「设置 → 应用」中显示的版本也随之更新。

### 新增
- **设置 → 清理与占用**：分别显示「升级暂存 / 缩略图缓存 / 日志」的占用，并可逐个或全部清理。
- **启动时自动清理过期升级暂存**：非当前版本的下载残留会被删除（此前失败或暂停的下载会一直占用磁盘）。
- **日志轮转**：`launcher.log` 超过 5 MB 自动轮转为 `launcher.log.1`，不再无限增长。
- **图库复用单个查看器窗口**：连续看图不再每张都新开窗口与渲染进程。
- **数据目录迁移后自动删除旧目录**：仅在复制零失败且新目录可用时执行，否则保留旧目录并记录原因。

### 改进
- **手动检查与自动检查各自独立的 24 小时冷却**：每天第一次手动检查必定联网，因此能立刻发现启动检查之后才发布的版本；
  自动检查仍为每天最多一次，两者互不影响（每天最多 2 次请求）。

### 文档
- README 以 **精致界面 + 高度自定义** 与 **原 · 铁 · 绝 · 舟 专属适配** 两项为核心功能。
